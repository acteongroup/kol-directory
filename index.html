One-time setup needed

This app stores KOL data in Firebase so every rep sees the same live database. The Firebase connection hasn't been configured yet.

  1. Go to console.firebase.google.com and create a project (or reuse an existing Acteon one).
  2. Add a Web App to the project, then copy the firebaseConfig object it gives you.
  3. Enable Authentication → Email/Password and Firestore Database (both work on the free Spark plan).
  4. Open this file in a text editor, find the firebaseConfig block near the top of the script, and paste your values in.
  5. Set Firestore rules so any signed-in user can read/write the kols collection, e.g.:
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /kols/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}

Save the file and re-open it (or re-deploy to Netlify). This screen will disappear once a valid config is detected.
